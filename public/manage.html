Each reg. number (licence plate) is linked to one trailer ID and carrier. On the map these are filled in from here and can't be changed there.

Import from CSV file

Columns: Car / Supplier (DSV, INT…), Ilu / Trailer ID and Reg (licence plate), in any order. Comma or semicolon separated (Excel: Save as → CSV). New reg. numbers are added and changed ones updated; reg. numbers not in the file are kept. A reg. number listed twice with different details is skipped, so nothing is guessed.

Roles

  • Viewer: sees the map and history, changes nothing (e.g. a screen in the office).
  • Worker: can also change status, damaged and note on trailers in the yard.
  • Operator: can also add, move, depart and remove trailers, correct times and manage the trailer register.
  • Admin: can also manage users and carriers.
